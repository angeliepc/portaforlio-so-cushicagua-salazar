==================== 3. DROP frente a REJECT (nftables) ====================

$ sudo nft add table inet taller

$ sudo nft add chain inet taller entrada '{ type filter hook input priority 0; policy accept; }'

# 1) Sin regla (se espera ≈0,01 s y código 0)

$ time curl -s -o /dev/null -m 5 http://127.0.0.1:8080; echo "código: $?"
real: 0.06 s · código: 0

# 2) DROP: el portero calla (se espera ≈5 s y código 28)

$ sudo nft add rule inet taller entrada tcp dport 8080 drop

$ time curl -s -o /dev/null -m 5 http://127.0.0.1:8080; echo "código: $?"
real: 5.02 s · código: 28

# 3) REJECT: el portero dice «no» (se espera ≈0,01 s y código 7)

$ sudo nft flush chain inet taller entrada

$ sudo nft add rule inet taller entrada tcp dport 8080 reject with tcp reset

$ time curl -s -o /dev/null -m 5 http://127.0.0.1:8080; echo "código: $?"
real: 0.03 s · código: 7

$ sudo nft list table inet taller
table inet taller {
	chain entrada {
		type filter hook input priority filter; policy accept;
		tcp dport 8080 reject with tcp reset
	}
}
